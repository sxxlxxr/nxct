# NXCT

NXCT — терминальная библиотека игр, поиск по подключённым источникам Hydra и управление torrent-загрузками прямо в приложении. Windows-сборки пока нет.

## Установка на Linux x86_64

После публикации первого [релиза NXCT](https://github.com/sxxlxxr/nxct/releases) откройте терминал и выполните **одну команду**:

```sh
curl -fsSL https://raw.githubusercontent.com/sxxlxxr/nxct/main/install.sh | sh
```

Установщик скачает готовую сборку NXCT вместе с `rqbit`, проверит SHA-256 архива по опубликованным контрольным суммам и установит приложение **без `sudo`**. Перед запуском удалённого установщика можно [прочитать его код](https://github.com/sxxlxxr/nxct/blob/main/install.sh).

Запуск: `~/.local/bin/nxct` (или `nxct`, если `~/.local/bin` находится в `PATH`). Системные Python и `rqbit` не требуются. Это терминальное, а не графическое приложение; запускайте его в терминале.

Приложение устанавливается в `${XDG_DATA_HOME:-$HOME/.local/share}/nxct/`. Настройки и библиотека находятся отдельно, в `~/.config/nxct/`; установщик их не заменяет. Скачанные игры установщик не трогает.

## Обновление

В NXCT откройте **Настройки → Проверить обновления → Установить обновление**. Проверка происходит только по нажатию. Перед установкой NXCT покажет подтверждение, завершит работу, проверит скачанный релиз и затем запустит новую версию. Если загрузка активна или поставлена на паузу, сначала завершите её либо уберите из очереди, оставив файлы на диске. При ошибке установки предыдущая версия остаётся доступной.

Кнопка установки работает в установленной сборке NXCT; при запуске из исходного `app.py` она недоступна. Релизы рассчитаны пока только на Linux x86_64.

## Источники и загрузки

При первом запуске доступны **FitGirl, GOG, onlinefix, Xatab и 0xEMPRESS**. SteamRIP не включён: его HTTPS-ссылки на файлообменники NXCT не умеет скачивать. Сохранённый пользователем список источников не заменяется при обновлении; новые источники добавляются в интерфейсе вручную.

Папка для скачивания **изначально не задана**. Загрузка начинается только после выбора игры, magnet-варианта и папки. NXCT не запускает скачанные файлы автоматически. Доступны пауза, продолжение и отмена с отдельным подтверждением удаления файлов. Очередь не сохраняется после закрытия приложения; файлы на диске остаются.

Источники сторонние: NXCT не проверяет безопасность файлов и права на их распространение. Используйте только материалы, на которые у вас есть права. При запросе каталога сервер Hydra видит ваш IP и запрос; при torrent-загрузке IP виден участникам сети. Каталог автоматически при запуске не запрашивается.

## Запуск из исходников

Нужен Python 3.12+ и отдельный `rqbit` в `PATH` для torrent-загрузок:

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python app.py
```

Для установленной сборки зависимости Python не нужны. Комплектный `rqbit` распространяется по Apache-2.0; текст лицензии включается в архив релиза.
